## 🛠️ Deployment Instructions to GitHub

To publish this repository to GitHub Pages under `fajarsyahriar.github.io`:

```bash
# 1. Masuk ke folder repositori ini
cd "D:\PRIBADI\web depoloy\fajarsyahriar.github.io"

# 2. Inisialisasi Git
git init

# 3. Tambahkan semua file
git add .

# 4. Commit pertama
git commit -m "Initial commit: developer portfolio & showcase for GitHub Pages"

# 5. Set branch utama ke main
git branch -M main

# 6. Hubungkan ke repository GitHub Anda
git remote add origin https://github.com/fajarsyahriar/fajarsyahriar.github.io.git

# 7. Push ke GitHub
git push -u origin main
```

Setelah di-push:
1. Masuk ke pengaturan repository di GitHub: **Settings** -> **Pages**.
2. Pastikan **Source** disetel ke: **Deploy from a branch**.
3. Pilih Branch: **main** dan folder: **/ (root)**, lalu klik **Save**.
4. Website akan otomatis live di: **https://fajarsyahriar.github.io/**
